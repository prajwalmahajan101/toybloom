## [0.1.0] — 2026-09-03

First public cut. A Scalable Bloom Filter as a service over Valkey — derive
`k`/`m` from `n`,`p`, store bits in Valkey, and grow automatically past `n`
while holding the false-positive rate ≤ `p`. Shipped as a Go library plus a Gin
REST API, fully observable with OpenTelemetry. Milestones M0–M10; v1 Definition
of Done met.

### Added

- **Optimal sizing** — derive `k` (hash count) and `m` (bits) from `n`,`p`
  ([ADR 0001](docs/ADR/0001-scalable-bloom-filter.md)).
- **Double hashing** — `k` positions from one xxhash128 digest via the
  Kirsch–Mitzenmacher technique ([ADR 0004](docs/ADR/0004-double-hashing.md)).
- **Scalable Bloom Filter core** — auto-chained stages with compounded
  false-positive probability ≤ `p`, and per-stage bitmap sharding across 4 MB
  keys for 1B+ scale ([ADR 0003](docs/ADR/0003-bitmap-sharding.md)).
- **Pluggable `BitStore`** — Valkey-backed storage plus an in-memory
  implementation for tests ([ADR 0002](docs/ADR/0002-valkey-bit-storage.md)).
- **Gin REST API** — 5 endpoints with a consistent response envelope, request
  validation, and an OpenAPI 3.1 contract that generates the server
  ([ADR 0006](docs/ADR/0006-api-contract-and-client-architecture.md)).
- **OpenTelemetry observability** — RED + bloom metrics, traces, and correlated
  logs over OTLP ([ADR 0007](docs/ADR/0007-otel-instrumentation-boundaries.md),
  [ADR 0008](docs/ADR/0008-per-filter-gauge-cardinality.md)), with a local
  `docker-compose` LGTM stack and auto-provisioned Grafana dashboards
  ([ADR 0005](docs/ADR/0005-observability-otel-lgtm.md)).
- **Integration, e2e & load verification** — statistical FPP + zero-false-negative
  tests against real Valkey, an HTTP e2e walk, and a k6 load test gating
  `p(99) < 200ms` ([ADR 0009](docs/ADR/0009-testing-strategy.md),
  [ADR 0010](docs/ADR/0010-load-testing-methodology.md)).

### Verified (v1 Definition of Done, all against real Valkey)

- Measured false-positive rate **0.00103** vs target `p = 0.01`.
- p99 Add/Exists latency **~15.95ms** (best-3-of-5), budget `< 200ms`.
- **Zero** false negatives across 1.2M+ requests.
